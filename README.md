## 🧩 Описание проекта

Проект исследует возможность **определения гамильтоновости графа** с использованием методов машинного обучения и нейронных сетей.  
Основная цель — **создание модели, способной точно классифицировать графы как гамильтоновы или негамильтоновы**.

Задача относится к NP-полным, и её классические алгоритмы требуют экспоненциального времени.  
Здесь реализован подход, при котором графы преобразуются в эмбеддинги с помощью **Graph2Vec**,  
а затем классифицируются с помощью традиционных ML-моделей (SVM, Random Forest и др.)  
и **многослойного персептрона (MLP)**.

---

## 🎯 Цели и задачи

**Цель:** разработать модель, определяющую гамильтоновость графа с точностью ≥ 95%.

**Основные задачи:**
- 🔹 Провести обзор свойств гамильтоновых графов  
- 🔹 Реализовать генерацию случайных связных графов  
- 🔹 Сформировать сбалансированный датасет  
- 🔹 Преобразовать графы в эмбеддинги (Graph2Vec)  
- 🔹 Обучить модели ML и MLP  
- 🔹 Провести анализ и сравнение точности

## 🧠 Архитектура решения

1. **Генерация графов**  
   - Алгоритм Maple генерирует связные графы на N вершинах  
   - Проверка гамильтоновости и сохранение метки (0 / 1)

2. **Создание датасета**  
   - Графы экспортируются в формате `.gexf`  
   - Метки — в `.Labels` файле  
   - Поддержка “полного” и “выборочного” режима (для баланса классов)

3. **Извлечение эмбеддингов**  
   - Используется модифицированный `graph2vec`  
   - Эмбеддинги размером 128–1024  
   - Полученные вектора сохраняются в `.csv`

4. **Обучение моделей**
   - ML-модели: KNN, Naive Bayes, Random Forest, SVC, SGD, Gradient Boost  
   - НС: MLP (3 Dense слоя: 350 → 50 → 2)  
   - Метрики: Accuracy, F1  

5. **Анализ и сравнение**  
   - Лучший результат: **MLP — 96%, LinearSVC — 95.2%**

## 📈 Обучение MLP

Архитектура сети:
Input (1024) → Dense(350, ReLU) → Dense(50, ReLU) → Dense(2, Softmax)
**Loss:** 0.12  **Accuracy:** 96%  
После 4–5 эпох рост точности прекращается (малый объём данных).  
Используется инициализация He и оптимизатор Adam.
